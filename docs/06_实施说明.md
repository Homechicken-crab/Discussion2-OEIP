# 准备代码与后续实施

## 当前代码能做什么

`src/deblur.py` 能读取 PNG/JPEG 等 Pillow 支持的普通图片，归正 EXIF 方向、选择 ROI、构建参数化直线 PSF，执行维纳滤波或阈值截断逆滤波，并导出编号候选及参数记录。

它尚不提供自动模糊核估计、自动候选优选、合成评价批处理、PSNR/SSIM 或最终展示制作。当前没有输入图片，默认参数只是用于命令示范。CLS 扩展尚未实现；主算法和基线已准备。`configs/candidates.example.json` 是人工审查用的参数示例，不会被 CLI 自动加载。

## 后续命令示例（当前未执行正式实验）

在项目根目录运行。先把原图存入 `data/private/input.jpg`；以下文件名仅为约定，不代表文件已经存在。

```powershell
python src/deblur.py data/private/input.jpg --out results/run01_wiener --lengths 9,17,25 --angles=-5,0,5 --ks 0.003
python src/deblur.py data/private/input.jpg --out results/run02_K --lengths 17 --angles 0 --ks 0.0003,0.001,0.003,0.01,0.03
python src/deblur.py data/private/input.jpg --out results/run03_inverse --lengths 17 --angles 0 --method inverse --threshold 0.02
```

如只处理局部，增加 `--roi 100,150,640,480`。坐标按 EXIF 归正后的图像计算，x 向右、y 向下，范围为 x≤列<x+宽、y≤行<y+高。该坐标只是语法示例，图片到位后重新选择。

PSF 的 L 是曝光期间连续轨迹跨度，单位为处理图像的像素；不是核矩阵边长，也不保证与 MATLAB fspecial 的离散 LEN 完全一致。默认没有缩放；若外部预先缩放了输入，需单独记录比例并换算 L。

θ=0° 为水平轴，正角度顺时针，方向以 180° 为周期。PSF 以至少每像素 64 个轨迹中点作积分采样，双线性分配到离散网格，最后归一化。L=0 给出中心脉冲，仅用于数值诊断。

默认反射扩边 64 像素。后续需比较扩边宽度并检查边缘；该默认值不保证对任意图片足够。`--pad 0` 是周期 FFT 对照。默认在近似线性光强域运算；`--srgb-domain` 仅用于记录明确的域选择对照。

## 输出含义

- `input_display.png`：实际参与处理的区域，固定 sRGB 显示，去除元数据。
- `candidate_NNN.png`：裁到 [0,1] 的显示图，无独立对比度拉伸。
- `candidate_NNN_raw.npy`：未裁剪浮点复原值，默认在线性域。
- `candidate_NNN_psf.npy`：用于该候选的离散核。
- `manifest.json`：原图哈希、代码指纹、Git 提交与脏状态、环境、区域、边界与参数、输出越界比例。
- `compare.html`：相同网格内的候选查看页，点击打开原尺寸；网页默认缩放只方便浏览，不代替原尺寸复核。

输出目录必须不存在，防止不同轮结果相互覆盖。工具不计算无真值的“准确率”，也不将某候选自动命名为最佳结果。GitHub 不会直接执行 HTML，需下载本地打开；Markdown 与 PNG 可直接浏览。

## 准备性自检

```powershell
python src/check_numerics.py
```

自检核归一化、中心对称、空域循环卷积与 FFT 的一致性、单位核下闭式结果、RGB 通道轴和颜色转换。只验证实现的一致性，不证明真实图像去模糊有效。

后续正式合成验证应增加 scikit-image 指标依赖及独立实验脚本，并采用验证规范中的校准/评价划分。当前不生成任何正式指标。
