# 验证与记录规范

本文保留早期后续验证设计，以下合成矩阵和指标条件尚未执行。已完成的工作是 Wiener_Filter 内的 MATLAB 实图复原；本轮只比较图像、检查脚本一致性和多区域表现，不计算评价指标。

## 1. 真实输入的评价

先预先指定 2-3 处细节区域，如一段文字、重复细纹、孤立边缘，并固定坐标。对同一区域的原图、基线、主算法作相同大小的并排展示。画面主体移动时，背景单独观察，避免仅选有利区域。

比较：可辨结构是否增加；双边缘和条纹是否减轻；是否产生光晕、噪声颗粒、颜色溢出和假细节。若有文字，不能用“猜对字”代替忠实复原，更不能把生成式补字混入结果。

无精确配准的清晰真值，不报告 PSNR、SSIM。另一张相似图片或静态参考图不自动构成逐像素真值。拉普拉斯方差、梯度、熵等只可作辅助描述，它们也会奖励噪声和振铃。

人工候选选择需记录：看到了什么、舍弃了什么、选择依据是什么。建议由指导 GPT 与执行者对相同候选编号交叉审查；这种审查仍属于主观证据，不是独立客观真值。

## 2. 后续合成对照矩阵

| 变量 | 准备值 |
|---|---|
| 数据 | 一张校准图 + 至少两张未用于调参的评价图；可用自行生成的图案与许可明确的公开图 |
| 模糊长度 | 9、21、33 像素 |
| 方向 | 0°、30°、60° |
| Gaussian 噪声标准差 | 0、0.005、0.015，在线性 [0,1] 域加噪，暂不裁剪观测值 |
| 随机种子 | 20261101、20261102、20261103 |
| 基线与算法 | 模糊输入；截断逆滤波；常数 K 近似维纳；CLS 仅选做 |
| 核失配 | 长度 ±4 像素；方向 ±5°、±10°，分别改变 |
| 边界对照 | 理想周期卷积作为实现检查；反射扩展后退化、裁剪、再独立扩边复原作为边界失配检查 |

如算力或时间不足可以先减少组合，但必须记录缩减后的实际矩阵。保存每个条件的逐图逐种子成绩，不只报最好一张。

调参只用校准图，固定规则后在评价图运行。若另外报告逐张图按真值选择 K 的结果，必须标为“已知真值调参上限”，不能与真实单图部署效果混淆。

## 3. 指标细节

合成图使用同一对齐坐标、固定动态范围 [0,1]。PSNR=10log10(1/MSE)，SSIM 显式使用 data_range=1；RGB 的通道处理方式须写清楚。建议同时报告全图和预先确定的内部区域，内部裁边取所有条件通用值，例如最大核半径再加安全余量，不随结果挑选。

主要指标基于裁到 [0,1] 的展示结果，并附未裁剪浮点结果的 MSE/越界比例以揭示不稳定输出。不允许通过逐图 min-max 拉伸提高观感或成绩。

若对相机 JPEG 的 sRGB 结果评价，标注评价域；不把线性域和 sRGB 域指标混表比较。

## 4. 每次运行记录

- 输入的相对名称与 SHA-256；原始分辨率；EXIF 方向是否已归正。
- 完整 ROI、是否缩放及比例；L 的像素基准与 θ 的坐标约定。
- 算法、K 或逆滤波阈值、PSF 离散规则、边界方式与扩边宽度。
- 代码提交 SHA、Python/依赖版本、种子、运行时间。
- 原始浮点复原数组、展示 PNG、参数 JSON、候选对比页面。
- 失败与异常；人工选择的候选编号及理由。

公开输入副本去除 EXIF，但保留原始文件哈希用于本地审计。本次依用户要求公开同步讨论材料，包括所提供的两章课件与题目；含本机路径的转换中间文件留在本地。后续输入图片的公开展示副本应去除元数据，并检查画面是否含与讨论无关的私人信息。

## 5. 有价值的失败结论

核匹配时改善、核失配时失败 → 支持“核估计是瓶颈”；整图背景劣化、内部区域改善 → 支持“空间不变模型只局部适用”；小 K 振铃强、大 K 细节丢失 → 支持“稳定性与细节存在折中”。这些只是解释模板，实验没有出现时不能写入最终结论。
